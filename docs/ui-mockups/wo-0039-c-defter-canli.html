WO-0039/C — Defter & Canlı yüzeyleri · tasarım tabakası (onaya tabi, koda dokunulmadı)

Dört sorun, dört karar. Her kararın altında neden-seçim ve seçilmeyenler. Uygulama yalnız onayından sonra başlar.

Uygulama sırası (onaydan sonra): ① min-h-0 zincir düzeltmesi (gizli içerik kurtulur) → ② panele kesin yükseklik + id → ③ tek kenar CSS kuralı → ④ defterin canlı işaretçi kartı + geçiş + itiraz deliği → ⑤ tek yeni anahtar ("Canlı oturum" tr/en). Hepsi mevcut kit dili içinde; yeni geçiş/animasyon yok; ⏎ kuralı dokunulmaz.
