WO-0039 · Mockup — DOSYA: ray öldü, kararlar bağlamına indi

Onaya sunulan tasarım tabakası. Onaylanmadan tek satır uygulama kodu yazılmaz; düzeltme istenirse bu dosya güncellenir. Yerleşim + hiyerarşi + metin sözleşmesi gösterilir — piksel CSS değil. 5–7 numaralı kart gövdeleri mevcut kartlardır; mockup yalnızca yeni konumları gösterir.

⚡ ana iddia: alt bar (ray) hiçbir durumda yok — kararlar bağlamında, süreç denetimi canlı panelin başlığında
mimar uygulayıcı doğrulayıcı amber = "seni bekliyor"
Kabul özeti — neyi neden yapıyoruz: ray, karar ile denetimi tek çubukta birleştiriyordu; kararların bağlamından fiziksel uzaklığı eylem-bağlam mesafesi yaratıyordu. Bu tasarım kararları dosyanın akışına (plan bölümü, hata/izin/kapanış kartları), süreç denetimini canlı panelin başlığına yerleştirir ve boşuyken hiçbir şey render etmez. ⏎ hâlâ geçerli birinciyi ateşler (Onayla / Bitti / Sürdür / Yeniden dene / Plan iste) — asla Kapat'ta, asla izin anında. "hazır"×N, "Plan commiti bekleniyor" ve İngilizce görev adları (üretici istem + WO-0001'de elle düzeltme) gider; "Kapılarda" çipi tooltip ile ne yaptığını anlatır.
