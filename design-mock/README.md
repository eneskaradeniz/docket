# design-mock — throwaway design reference

Standalone HTML mockup (Tailwind via CDN + vanilla JS) of the **approved** Docket UI direction:
warm dark "aged-paper-meets-terminal", evidence-ticket cards, the plan-driven work-order flow,
Turkish copy.

**This is NOT the real app** — it is not imported by anything and not part of the build. It exists
only to validate look, flow, and the workspace/work-order/plan/closure interactions before porting.
The product source of truth is [`../docs/PRODUCT.md`](../docs/PRODUCT.md). Once the design is ported
into the real React renderer (`src/ui/`), this directory is deleted.
